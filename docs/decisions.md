- 2026-11-21 · **Fixture price dates are rebased on load** so the newest row is "yesterday"; otherwise the fixture would go stale in real time. · BUILD 2.5
- 2026-11-21 · **Local search is capped by iterations (400), not by a 150 ms clock**, because a clock would make results depend on machine speed and break "same seed → deep-equal" (PLN-1). Speed is enforced by `pnpm bench:engine` (p95 166 ms on 14 days × 200 recipes). · §9.5, PLN-1
- 2026-11-21 · **Budget fallback is split across the user action**: a balanced plan over budget is returned with status `over` + shortfall; "Fit my budget" re-runs with `mode: 'cheapest'`, and only a cheapest-mode plan that is still over computes `maxAffordableDays` (binary search; 0 if not even one supper fits). Matches the §7.2 UI and BUILD 4.4 while keeping §9.6's order (balanced → cheapest → days). · §9.6, PLN-5
- 2026-11-21 · **Variety limits are pro rata, rounded up**: protein ≤ ceil(2·days/7), starch ≤ ceil(3·days/7); cheapest mode needs ≥ max(1, floor(days/7)) meat-free suppers. If the recipe pool is too small, the greedy relaxes protein/starch caps for that slot rather than leaving it empty; duplicates are never allowed. Soft variety penalty = repeats per protein + ½ repeats per starch + same protein on consecutive days. · PLN-4, §9.5
- 2026-11-21 · **Unpriceable ingredients carry a R500 objective penalty per meal**, so recipes the shop can't price are chosen only when nothing else fits; they are still never estimated and stay out of totals. · PLN-10, §9.5
- 2026-11-21 · **Two-shop split**: items the main shop can't price go to the top-up shop; that forced trip waives the R30 total threshold for other items (each must still save ≥ R5). · PLN-12
- 2026-11-21 · **Meal cost = each ingredient's paid cost split across the meals that use it, by quantity (largest remainder)**, so Σ meal costs = paidCents exactly; leftover cost is carried by the meals. Pack efficiency compares buying each meal separately vs the joint basket, both without pantry, and is never added to savings. Optional recipe ingredients are not bought. Day 1 = `asOf`. · §9.7, §9.9
- 2026-11-21 · **"Until the 25th" plans suppers up to the day before payday; "Until month-end" plans through the last day of the month**; all periods clamp to 3–14 days. A payday on the 29th–31st falls on the last day of shorter months. Payday defaults to the 25th until set in Settings. · ONB-4, §18 #11
- 2026-11-21 · **E2E runs against a production build** (`next build && next start`) because first-compile delays in `next dev` made tests flaky; `E2E_DEV=1` keeps the dev-server option. · BUILD §6.4

- 2026-11-21 · **Store distance on the plan header comes from the device** (saved shops), never from the server: the server does not keep the user's location. · §15 coarse location
